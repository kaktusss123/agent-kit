# Kanban Discipline Knowledge

## Source Of Truth

- Kanban owns task state, decisions, blockers, review outcome, and verification summary.
- Chat history is not a durable source of process state.

## Minimum Task Record

- Objective
- Scope and non-goals
- Acceptance criteria
- Current stage
- Next step
- Decisions and blockers
- Verification and review outcome

## Done Rule

- Do not mark a task done without both verification evidence and review outcome.
