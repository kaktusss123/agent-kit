# Scenario map

Run commands from the repository root. Follow the shared isolation contract in `../SKILL.md` before commands that exercise the runtime.

| User entry point / capability | Scenario | Coverage |
| --- | --- | --- |
| `agent-kit install`, skill discovery in Pi/Codex/Claude Code | [Installation](installation.md) | Layout, links, host packaging; live Codex discovery when the pinned CLI is present |
| Named same-repository arena/swarm lanes and owner dispatch | [Managed lanes](managed-lanes.md) | Separate snapshots/branches/outputs, same-tree and alias refusal, cleanup guards |
| Pi advisory reflection on naturally occurring user turns | [Skill reflection](skill-reflection.md) | Cadence, successful imports, session branching/reload, actual loader |

This map is selective, not an exhaustive catalog of tests. Snapshot publication, unrelated extensions and live model/provider behavior retain their existing checks in CONTRIBUTING.md. No paid model or production-load scenario is implied here. Run the full extension suite when shared runtime changes justify it; skipped or unavailable live checks remain explicit gaps.
