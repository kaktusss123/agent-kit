# Напоминание о навыках

Расширение Pi незаметно добавляет рекомендацию рассмотреть `reflect` примерно на каждом восьмом принятом сообщении пользователя, если на текущей ветке уже прочитан хотя бы один `SKILL.md` или успешно раскрыта команда `/skill:name`. Напоминание не запускает отдельный запрос модели и не разрешает изменение файлов. Содержимое сессии остаётся данными, а не инструкцией к изменению навыков.

Источник сообщения и распознанная команда сохраняются в записях текущей ветки, но учитываются только после сохранения следующего сообщения `user`. Если запуск прервался до этого, следующая метка источника заменяет незавершённую. При перезагрузке и переходах по дереву состояние восстанавливается из текущей ветки; у дочерних агентов с `PI_SUBAGENT_ID` расширение отключено. История других сессий не просматривается.

Распознаётся успешный вызов инструмента `read` для `SKILL.md`; произвольные команды оболочки не анализируются. Чтения, скрытые внутри другого инструмента и не сохранившие отдельный результат в сессии, не распознаются. Сообщения в очереди учитываются при доставке, а само напоминание добавляется только при следующем обычном запуске пользователем. При смешанных источниках или переполнении очереди её сообщения консервативно не учитываются: Pi не сообщает расширению источник доставленного сообщения или очистку очереди.
