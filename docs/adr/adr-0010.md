# ADR-0010: роли субагентов в Claude Code

Status: Accepted
Date: 2026-10-14
Частично заменён: ADR-0011 (алиасы моделей вместо закреплённых ID, словарь ролей, per-machine remap через `env`, R2 закрыт)

## Context

В Pi два типа субагентов: RepoOwner и «все остальные», а цена и effort задаются классами моделей (`modelClass`). В Claude Code для RepoOwner не было своего system prompt, а встроенный `Explore` работает на модели по умолчанию. Спецификация a9 считала порт model-classes ненужным. Нужно получить ту же двухтиповую модель без набора агентов под каждый уровень цены.

## Decision

1. Роли — файлы определений агентов в `claude-code/agents/*.md`. Инсталлер ставит их симлинками в `~/.claude/agents/*` тем же механизмом, что `claude-code/commands/*` → `commands/*`. В `agents/` плагина они не кладутся: агенты плагина получают namespace, загрузка агентов из плагина-каталога skills не документирована, а пользовательские агенты имеют приоритет над плагинными.
2. Ровно два файла:
   - `Explore.md` переопределяет встроенный `Explore`: `model: claude-haiku-5-5`, `effort: low`, `tools: Read, Grep, Glob`, `omitClaudeMd: true`. Frontmatter обязан начинаться с `---` в первой строке: ведущая пустая строка молча отключает определение.
   - `repo-owner.md`: `model: claude-sonnet-5-5`, `effort: medium`, все tools. Тонкий system prompt только со стабильными правилами владельца; контракты остаются в skills.
3. «Все остальные» — встроенный `general-purpose`; уровень цены выбирает параметр `model` вызова Agent: `haiku` — дешёвые ограниченные задачи, без `model` — модель сессии, `opus` — независимый ревьюер (независимость даёт свежий контекст, а не отдельный тип агента). Effort каждой модели берётся из `modelSettings.<model>.effortLevel` в `~/.claude/settings.json`; agent-kit этот файл не пишет и лишь документирует рекомендуемый фрагмент в README. Единственные переопределения на уровне агента — `effort` в `Explore` и `repo-owner`.
4. В вызове Agent к агенту, у которого определение задаёт `model`, `model` не передаётся: параметр перекрывает frontmatter.
5. Новый тип агента заводится только если роли нужен свой system prompt или набор tools, никогда ради цены или effort.
6. Haiku-уровень не используется как единственный авторитет для анализа первопричин, security review и дизайнерских решений.

## Consequences

- Model-classes из Pi не портируются: определения агентов и `modelSettings` — их эквивалент в Claude Code.
- Конфликтующий пользовательский файл с тем же именем в `~/.claude/agents/` остаётся нетронутым (обычная семантика reconcile), роль в этом случае не ставится.
- Известный открытый вопрос R2: документация Claude Code не говорит, приоритетнее ли `effort` во frontmatter, чем `modelSettings.<model>.effortLevel`. Если нет, `Explore` работает на haiku high. Проверяется эмпирически после установки; решение не принято.
