# ADR-0006: inherited live inspection channel

Status: Accepted
Date: 2026-09-24

## Context

Pi RPC is the only control channel. Native Pi RPC does not expose an extension-defined live read of another extension's in-memory runtime; transcript/session entries are neither a live read nor a suitable status protocol. The external controller therefore needs a narrow process-local read path for the current agent-kit snapshot.

## Decision

Agent-kit exposes an optional versioned bounded JSONL inspection channel over two already-open inherited file descriptors named `AGENTKIT_INSPECT_REQUEST_FD` and `AGENTKIT_INSPECT_RESPONSE_FD`. The channel is read-only, non-durable, non-reconnectable, and lives exactly as long as the Pi process. It is inert unless both descriptors are numeric and valid pipe-like descriptors; it creates no files, sockets, listeners, daemon, registry, journal, or event stream.

This channel is a narrow, deliberate read-only exception to the ADR-0005 decision that an external client communicates with a live Pi process only through the standard RPC protocol: it carries no commands, cannot mutate runtime, session, or telemetry state, and exists solely as a live read-only projection of the current in-process snapshot. It is not a control channel and must not grow one; ADR-0005 itself remains unchanged and continues to govern control traffic.

The inspection extension reads the live subagent runtime through a minimal internal read seam. It uses the existing `agentDetailView` contract and workspace-run view for enrichment, while lifecycle and state remain owned by `subagents`. Task snapshots delegate to the existing `taskStatus` semantics using the current session cwd at request time. The transport is process-owned and has exactly one active stream pair even when Pi reruns extension factories for session changes. Request and response descriptors must be distinct existing pipe or socket descriptors above fd 2. The handler reads only from the request descriptor and writes only to the response descriptor; it does not infer direction from OS-level descriptor mode flags because runtime-inherited stdio descriptors may be bidirectional. Frames are bounded by their byte length including the newline, and UTF-8 decoding occurs only after a complete frame. Requests and responses fail closed on malformed or unsupported protocol values; EOF or I/O errors stop the channel without taking down Pi.

Child Pi processes never inherit either inspection environment variable. The legacy `/agentkit-status` command remains a deprecated compatibility carrier and uses the same snapshot semantics; it does not gain new features.

The agent-kit node does not import agent-kit extension modules, and standalone agent-kit does not depend on ZAVOD.

## Consequences

The channel is intentionally a one-process observation seam: a controller must launch the Pi with inherited descriptors and cannot reconnect after process death. Live reads do not modify transcripts, session entries, or telemetry events. A future durable or bidirectional interface would require a separate decision.
