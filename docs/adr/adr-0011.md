# ADR-0011: алиасы моделей и словарь ролей субагентов в Claude Code

Status: Accepted
Date: 2026-10-28
Частично заменяет: ADR-0010, решения 2 и 3 (закреплённые ID моделей, источник effort) и открытый вопрос R2

## Context

ADR-0010 закрепил в `Explore.md` и `repo-owner.md` конкретные ID моделей (`claude-haiku-5-5`, `claude-sonnet-5-5`). Коллегам с другим набором моделей или провайдером ID приходится править в симлинкованном файле репозитория. Параллельно Pi получил фиксированные роли субагентов (`explore`, `helper`, `review`, `owner`) с привязкой к модели на машине; Claude Code должен говорить на том же словаре.

## Decision

1. Роли Pi ложатся на Claude Code так:
   - `explore` → агент `Explore`;
   - `owner` → агент `repo-owner`;
   - `review` → `general-purpose` с `model: opus` в вызове Agent;
   - `helper` → `general-purpose` без `model`.
2. `Explore.md` и `repo-owner.md` задают `model` алиасом: `haiku` и `sonnet`. Остальные поля (`effort`, `tools`, `omitClaudeMd`) без изменений. Инсталлер по-прежнему только ставит симлинки (ADR-0007), ничего не рендерит.
3. Per-machine подмена модели — штатный `env` в `~/.claude/settings.json`: `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL`, `ANTHROPIC_DEFAULT_OPUS_MODEL` (источник: https://code.claude.com/docs/en/model-config). Подмена действует на алиас целиком, а не на роль: `review` и `owner` нельзя развести, если они делят алиас. Это принятый компромисс; agent-kit `settings.json` не пишет.
4. Effort: `effort` во frontmatter агента перекрывает уровень effort сессии, но не переменную окружения `CLAUDE_CODE_EFFORT_LEVEL` (источник: https://code.claude.com/docs/en/model-config). Поэтому `Explore` работает на `low`, пока эта переменная не задана. Решения 3 ADR-0010 про `modelSettings.<model>.effortLevel` как источник effort для `general-purpose` это не меняет.
5. Остальные решения ADR-0010 (расположение определений, два файла, `model` не передаётся агентам с собственным `model`, новый тип агента только ради system prompt или tools, haiku не единственный авторитет) остаются в силе.

## Consequences

- R2 из ADR-0010 закрыт пунктом 4.
- Открытый риск R3: документация не говорит явно, что `ANTHROPIC_DEFAULT_*` применяется к алиасу во frontmatter субагента (описана подмена алиасов в `--model`, `/model` и `model` настроек). Нужна эмпирическая проверка на машине с подменой; до неё не утверждается, что `Explore` и `repo-owner` следуют подмене.
- Пока алиасы не подменены, они указывают на актуальные для провайдера версии моделей, то есть версия модели больше не фиксируется репозиторием.
