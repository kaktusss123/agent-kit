# Источники идей

Навыки `arena`, `swarm`, `correct`, `reflect`, `benchmark-checklist`,
`formal-verification` и дополнения к `verification-design` адаптируют идеи
[pstack](https://github.com/cursor/plugins/tree/e1cc03121a0e71129a4fb730d7c5528a0a3e43c8/pstack)
(Lauren Tan, 2026). Зафиксированный источник:
`cursor/plugins@e1cc03121a0e71129a4fb730d7c5528a0a3e43c8`, каталог `pstack`.
Процедуры и привязки к средам написаны для agent-kit; они не предполагают
наличия Cursor или его настроек. Автоматическое напоминание о рефлексии —
отдельное расширение Pi, а не переносимый hook для всех сред.
